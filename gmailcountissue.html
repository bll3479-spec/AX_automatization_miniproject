원인 1 — Batch API 응답 실패 무음 유실 주원인 수정 완료

수정 전 — exception 무시, 재시도 없음

# 배치 콜백 — exception 체크 없음 def _cb(request_id, response, exception): if response is not None: raw_by_id[request_id] = response # 429/503 응답 → response=None → 조용히 skip # 재시도 로직 없음 → 영구 유실

수정 후 — 실패 ID 추려 지수 백오프 재시도

# 실패한 ID만 모아 재시도 def _cb(request_id, response, exception, _bucket=found): if exception is None: _bucket[request_id] = response remaining = [mid for mid in remaining if mid not in raw_by_id] # 최대 4회 재시도: 0s→0.5s→1s→2s

원인 2 — Gmail 페이지 커서 드리프트로 중복 ID 유실 보조 원인 수정 완료
