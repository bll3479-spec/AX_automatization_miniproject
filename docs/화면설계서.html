자봐 화면 설계서

Gmail 이메일 자동 분류 웹 대시보드 — 화면 구조·컴포넌트·인터랙션 흐름 명세

버전 v1.0
작성일 2026-07-01
브랜치 claude/email-auto-categorization-ccab9j
1

앱 개요

자봐는 Gmail 이메일을 자동으로 분류·태깅해 주는 웹 대시보드입니다. FastAPI 백엔드가 정적 프론트엔드를 함께 서빙하며, 브라우저 한 탭으로 모든 기능을 사용합니다.

기술 스택

레이어기술비고
백엔드 FastAPI Python 3.11+ uvicorn으로 실행, 정적 파일 서빙 포함
프론트엔드 바닐라 HTML/CSS/JS 빌드 도구 없음, 단일 페이지(SPA 유사)
분류 엔진 규칙 기반 + Claude API 폴백 ANTHROPIC_API_KEY 없으면 규칙만 사용
Gmail 연동 Google API (OAuth2) credentials.json + token.json 로컬 저장

화면 목록

#화면명진입 조건주요 역할
1 홈 화면 (전체 뷰) 초기 진입 / "전체" 칩 선택 메인 4개 카테고리 큰 카드 + 기타 알림 요약
2 카테고리 상세 화면 카테고리 칩 클릭 선택 카테고리 이메일 목록 + 페이지네이션
3 분류 실행 중 상태 "분류 실행" 버튼 클릭 진행률 바 표시, 버튼 비활성화
