## 1. 앱 개요

**자봐**는 Gmail 이메일을 자동으로 분류·태깅해 주는 웹 대시보드입니다. FastAPI 백엔드가 정적 프론트엔드를 함께 서빙하며, 브라우저 한 탭으로 모든 기능을 사용합니다.

### 기술 스택

| 레이어 | 기술 | 비고 |
|---|---|---|
| 백엔드 | FastAPI (Python 3.11+) | uvicorn으로 실행, 정적 파일 서빙 포함 |
| 프론트엔드 | 바닐라 HTML / CSS / JS | 빌드 도구 없음, 단일 페이지(SPA 유사) |
| 분류 엔진 | 규칙 기반 + Claude API 폴백 | `ANTHROPIC_API_KEY` 없으면 규칙만 사용 |
| Gmail 연동 | Google API (OAuth2) | `credentials.json` + `token.json` 로컬 저장 |

### 화면 목록

| # | 화면명 | 진입 조건 | 주요 역할 |
|---|---|---|---|
| 1 | 홈 화면 (전체 뷰) | 초기 진입 / "전체" 칩 선택 | 메인 4개 카테고리 큰 카드 + 기타 알림 요약 |
| 2 | 카테고리 상세 화면 | 카테고리 칩 클릭 | 선택 카테고리 이메일 목록 + 페이지네이션 |
| 3 | 분류 실행 중 상태 | "분류 실행" 버튼 클릭 | 진행률 바 표시, 버튼 비활성화 |

## 2. 카테고리 체계

8개 카테고리를 **메인(4개)**과 **기타(4개)**로 구분합니다. 메인 카테고리는 홈 화면에서 큰 섹션 카드로 강조 표시되고, 기타 카테고리는 하단 "기타 알림" 요약 섹션에 컴팩트하게 표시됩니다.

### 메인 카테고리 (홈 화면 큰 카드)

| 순서 | ID | 표시명 | 색상 | 분류 기준 (요약) |
|---|---|---|---|---|
| 1 | `newsletter` | 뉴스레터 | `#059669` (초록) | List-Unsubscribe 헤더, 뉴스레터·구독·digest 키워드 |
| 2 | `announcement` | 공고 | `#0891b2` (청록) | 공고·입찰·채용·RFP·입찰공고 키워드 |
| 3 | `work` | 업무 | `#7c3aed` (보라) | 회의·Jira·Slack·GitHub·캘린더·일정 키워드 |
| 4 | `payment` | 결제 관련 | `#2563eb` (파랑) | 결제·영수증·청구서·invoice·receipt·주문확인 |

### 기타 카테고리 (기타 알림 요약)

| 순서 | ID | 표시명 | 색상 | 분류 기준 (요약) |
|---|---|---|---|---|
| 5 | `security` | 보안 | `#e11d48` (빨강) | 인증번호·OTP·로그인알림·비밀번호 재설정 (LLM 차단) |
| 6 | `promotion` | 프로모션 | `#ea580c` (주황) | 할인·세일·쿠폰·% off·이벤트·신상품 키워드 |
| 7 | `report` | 보고서 및 간행물 | `#854d0e` (갈색) | 보고서·리포트·백서·간행물·통계·연구 키워드 |
| 8 | `other` | 기타 | `#6b7280` (회색) | 규칙 미매칭 + LLM 폴백 실패 또는 미사용 |

> **보안(security) 특이사항:** 규칙 매칭으로만 판정하며, 이 카테고리로 분류된 메일의 본문은 Claude API에 절대 전달되지 않습니다.

## 3. 공통 컴포넌트

### 3-1. 상단 바 (TopBar)

모든 화면 최상단에 항상 표시되는 컨트롤 영역입니다.

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 📬 자봐        [데모 데이터 ▼] [20건 ▼] [□ Gmail에 라벨 적용] [분류 실행] [적용 2] │
└──────────────────────────────────────────────────────────────────────────┘
```

| 요소 | ID | 기본값 | 동작 | 상태 변화 |
|---|---|---|---|---|
| 소스 선택 | `#source-select` | 데모 데이터 | 변경 즉시 `runClassify()` 호출 | `gmail` 선택 시 라벨 적용 체크박스 활성화 |
| 건수 선택 | `#limit-select` | 20건 | 변경 즉시 `runClassify()` 호출 | — |
| Gmail에 라벨 적용 | `#apply-labels-checkbox` | off (비활성) | 소스가 `gmail`일 때만 활성 | 소스 변경 시 자동 체크 해제 |
| 분류 실행 | `#refresh-btn` | 활성 | `runClassify()` 호출 | 분류 중: "분류 중..." 텍스트 + disabled |
| 적용 | `#apply-overrides-btn` | 비활성 (회색) | 수동 정정 일괄 서버 반영 | 미결 정정 1개 이상: 활성(초록), 숫자 배지 표시 |

---

### 3-2. 카테고리 요약 칩 (Summary Chips)

분류 완료 후 각 카테고리 건수를 색상 칩으로 표시합니다.

```
[전체 24건] [뉴스레터 8] [공고 3] [업무 5] [결제 관련 2] [보안 1] [프로모션 3] [보고서 및 간행물 1] [기타 1]
```

| 상태 | 표현 |
|---|---|
| 선택됨 (active) | `outline: 2px solid #1f2937` (검정 테두리) |
| 미선택 | outline 없음, hover 시 opacity 0.85 |
| 전체 칩 | 항상 첫 번째, 배경색 `#1f2937` (다크) |

---

### 3-3. 카운트 정보 배너

소스가 Gmail일 때만 표시됩니다.

```
ℹ️ 자봐는 24건의 개별 메일을 읽었습니다. Gmail 받은편지함 숫자(대화 기준)와 다를 수 있어요
   — 하나의 대화에 메일이 여러 개면 자봐는 각각 따로 셉니다.
```

- **배경:** `#eff6ff` · **텍스트:** `#1e40af` · **하단 선:** `#dbeafe`

### 3-4. 분류 진행률 바

배치 분류 중 진행 상황을 시각화합니다.

```
진행 중: [████████░░░░░░░░]  12/20건 분류 중... (60%)
완  료:  [████████████████]  분류 완료 (20건)
```

| 상태 | 진행 바 색상 |
|---|---|
| 진행 중 | `#2563eb` (파랑) |
| 완료 | `#059669` (초록), `.is-done` 클래스 추가 |

### 3-5. 확인 모달 (Confirm Modal)

적용 버튼 또는 변경 버튼 클릭 시 표시됩니다.

```
┌─────────────────────────────┐
│                             │
│  라벨을 적용하시겠습니까?        │
│                             │
│      [   네   ]  [ 아니오 ]  │
│                             │
└─────────────────────────────┘
```

| 트리거 | 메시지 패턴 | 네 동작 | 아니오 동작 |
|---|---|---|---|
| `#apply-overrides-btn` 클릭 | 라벨을 적용하시겠습니까? | `applyPendingOverrides()` 실행 | 모달 닫힘, 상태 유지 |
| `#bulk-apply-btn` 클릭 | N개 메일을 '[카테고리]'(으)로 변경하시겠습니까? | `applyBulkOverride()` 실행 | 모달 닫힘, 선택 상태 유지 |

---

### 3-6. 토스트 알림 (Toast)

화면 상단 중앙에 일시적으로 나타나는 피드백 메시지입니다.

```
        ╔═══════════════════════════════════════════════════╗
        ║ 3개 메일을 '업무'(으)로 변경 예정 — '적용'을 눌러 반영하세요. ║
        ╚═══════════════════════════════════════════════════╝
```

- **위치:** 화면 상단 중앙 (`position: fixed; top: 20px; left: 50%; transform: translateX(-50%)`)
- **배경:** `#1f2937` · **글자:** 흰색

---

### 3-7. 에러 배너 (Error Banner)

API 요청 실패 또는 Gmail 연동 오류 시 표시됩니다.

```
⚠ 분류는 완료됐지만 2건은 Gmail 라벨 적용에 실패했습니다. "분류 실행"을 다시 눌러 재시도해보세요.
```

- **배경:** `#fee2e2` · **텍스트:** `#991b1b`

---

### 3-8. 선택 플로팅 바 (Bulk Action Bar)

1개 이상 이메일 선택 시 화면 하단에 고정 표시됩니다.

```
 ╔═══════════════════════════════════════════════════════════╗
 ║  ⠿  뉴스레터 2건 · 업무 1건  |  총 3개 선택  [업무 ▼] [변경] [선택 전체 해제]  ║
 ╚═══════════════════════════════════════════════════════════╝
```

| 요소 | 동작 |
|---|---|
| ⠿ 드래그 핸들 | 마우스/터치 드래그로 화면 내 임의 위치 이동 (viewport 경계 이탈 방지) |
| 선택 카운트 텍스트 | 카테고리별 선택 수 + 전체 합산 실시간 표시 |
| 카테고리 드롭다운 | 변경 대상 카테고리 선택 |
| 변경 버튼 | 확인 모달 → `applyBulkOverride()` (pending에 스테이징, 즉시 서버 반영 아님) |
| 선택 전체 해제 | `clearSelection()` 호출, 체크박스 전부 해제 |
| 숨김 조건 | 선택 이메일 수 = 0 |

- **기본 위치:** `bottom: 24px`, 화면 중앙 (`left: 50%; transform: translateX(-50%)`)
- **드래그 후:** 인라인 `style.left`, `style.top`으로 자유 위치 지정

### 레이아웃 규칙

| 항목 | 값 |
|---|---|
| 메인 카드 그리드 | `grid-template-columns: repeat(2, minmax(500px, 1fr))` |
| 좁은 화면 (≤640px) | 단일 컬럼으로 전환 |
| 카드 미리보기 수 | 카테고리당 최대 5건, 초과 시 "전체 N건 보기 →" 버튼 표시 |
| 카드 높이 통일 | `equalizeCardHeights()` — DOM 렌더 후 JS로 최대 높이 동기화 |
| 섹션 카드 헤더 하단 선 | `border-bottom: 3px solid [카테고리 color]` |
| 기타 알림 배경 | `#fafafa`, border `#e5e7eb` |

### 섹션 카드 헤더 상태

| 요소 | 표시 조건 |
|---|---|
| 카테고리 이름 (색상 강조) | 항상 |
| N건 카운트 | 항상 |
| "N개 선택" 배지 (다크 배경) | 해당 섹션 선택 수 > 0 |
| "선택 해제" 버튼 | 해당 섹션 선택 수 > 0 |

### 상세 규칙

| 항목 | 값 |
|---|---|
| 테두리 색상 | 선택 카테고리의 color 값 (`--cat-color` CSS 변수) |

| 테두리 마진 | 좌우 `clamp(8px, 1.5vw, 16px)` |
| 페이지당 이메일 수 | 10건 (`PAGE_SIZE` 상수) |
| 이메일 카드 선택 상태 | background `#eff6ff`, border `#93c5fd` |
| 분류 근거 표시 | 우측: "근거: [matched_rule] ([confidence]%)" |
| 모바일 (≤480px) | 카드 flex-direction column, 우측 영역이 하단으로 내려감 |

## 6. 화면 3 — 분류 실행 중 상태

"분류 실행" 버튼 클릭 시 나타납니다. 기존 화면을 덮어쓰지 않고 진행률 바만 추가됩니다.

### 레이아웃 구조

```
┌────────────────────────────────────────────────────────────┐
│ 📬 자봐   [데모 데이터 ▼] [20건 ▼] [분류 중... (비활성)]       │
├────────────────────────────────────────────────────────────┤
│ [████████████░░░░░░░░░░░░]  12/20건 분류 중... (60%)        │
├────────────────────────────────────────────────────────────┤
│ (이전 분류 결과 유지)                                          │
└────────────────────────────────────────────────────────────┘
```

### 상태 규칙

| 상태 | 변화 |
|---|---|
| 분류 실행 버튼 | 텍스트 "분류 중...", `disabled = true` |
| 소스/건수 선택 | 변경 가능 (재클릭 시 이전 요청 결과 무시, 새 요청 실행) |
| 진행률 바 | 0→100% 배치(10건) 단위로 갱신, 완료 시 초록색 |
| 기존 이메일 목록 | 이전 결과 유지, 덮어쓰기 없음 |
| 경쟁 조건 처리 | `_classifyRun` 카운터로 오래된 요청 결과 자동 무시 |

## 8. 인터랙션 흐름

### 8-1. 분류 실행 흐름

```
소스/건수 선택 또는 버튼 클릭
    → GET /api/emails/raw
    → POST /api/classify/batch (10건씩 반복)
    → 진행률 바 갱신 (0→100%)
    → 화면 갱신 (홈/상세 렌더)
```

### 8-2. 수동 정정(Override) 흐름

```
카드 드롭다운에서 카테고리 변경
    → 로컬 스테이징 (pendingOverrides 딕셔너리에 저장)
    → 적용 버튼 활성화 + 숫자 배지 갱신
    → 적용 버튼 클릭 → 확인 모달 표시
    → "네" 클릭
        → POST /api/emails/{id}/override (건별 순차 처리)
        → 재분류 (기존 rawEmails 재사용)
        → 화면 갱신, 토스트 소멸
```

### 8-3. 일괄 변경 흐름

```
체크박스로 이메일 1개 이상 선택
    → 플로팅 바 표시
    → 카테고리 선택 후 "변경" 클릭
    → 확인 모달: "N개 메일을 '[카테고리]'(으)로 변경하시겠습니까?"
    → "네" 클릭
        → overrideCategory() × 선택 수 (pending 스테이징)
        → 선택 초기화, 플로팅 바 숨김
        → 토스트: "N개 메일을 '[카테고리]'로 변경 예정 — '적용'을 눌러 반영하세요."
        → 적용 버튼 활성화
    → "아니오" 클릭 → 모달 닫힘, 선택 상태 유지
```

### 8-4. Gmail 라벨 적용 흐름 (선택적)

```
소스: "실제 Gmail" + "Gmail에 라벨 적용" 체크
    → "분류 실행" 클릭
    → POST /api/classify { source: "gmail", apply_labels: true }
    → Gmail에 AX/카테고리 라벨 자동 생성·적용
    → 실패 건 있으면 에러 배너 표시 (분류 결과는 정상 표시)
```
